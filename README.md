

## Lab 1: Variables and Functions — Reflection Questions

### 1. How did you approach creating more flexible functions with parameters?

I learned how to use parameters to make functions more flexible. For example, I used `firstName` and `lastName` to accept different names and capitalized the first letter of each name using `.toUpperCase()`. This helped me understand how one function can work with different inputs.

### 2. What challenges did you face while incorporating conditional logic in your functions?

One challenge I faced was making sure my functions handled different inputs correctly. I used `if`, `else if`, and `else` statements to check conditions and return the correct results. I also had to check for invalid inputs so my functions would return an error message instead of an incorrect calculation. Testing different values helped me understand how conditional logic works.

### 3. How does refactoring improve the readability and maintainability of your code?

Refactoring helps make code easier to read, understand, and update. In this lab, I updated my `calculateTotalCost()` function to include an optional discount parameter. Instead of creating a separate function, I improved the existing one. This taught me how to add new features while keeping my code organized and reusable.
